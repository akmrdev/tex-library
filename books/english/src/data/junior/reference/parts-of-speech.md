# 品詞早見表

英語の文は、**8つの品詞**(単語の働きのグループ)の組み合わせでできています。それぞれの役割と見分け方を知ると、長い文も読めるようになり、英作文でも語順や形を正しく選べるようになります。

## 品詞とは

同じ単語でも文中での働きによって品詞が変わることがあります(例:water は名詞「水」にも動詞「水をやる」にもなる)。品詞を見抜くポイントは「**その単語が文の中で何をしているか**」です。

## 8品詞の一覧表

| 品詞 | 役割 | 見分け方 | 例 |
|---|---|---|---|
| 名詞 | 人・物・ことの**名前**。主語・目的語・補語になる | a / the / my の後ろ、of の後ろに来る | book, Tom, music, happiness |
| 動詞 | **動作や状態**を表す。文の中心になる | 主語の直後。時制により形が変化する | run, is, have, study |
| 形容詞 | 名詞を**修飾・説明**する。補語にもなる | 名詞の前、be動詞の後ろ(complement) | big, beautiful, happy |
| 副詞 | 動詞・形容詞・副詞・文全体を**修飾**する | 文のさまざまな位置。-ly で終わる語が多い | very, quickly, here, often |
| 前置詞 | 名詞の前に置かれ、**関係**を示す | 前置詞 + 名詞(句を作る)の形 | in, on, at, to, from, with |
| 接続詞 | 語・句・**節をつなぐ** | 2つの文・句の間にある | and, but, because, when, if |
| 代名詞 | 名詞を**受けて指し示す**(繰り返しを避ける) | 主語・目的語の位置で名詞の代わりになる | I, you, he, it, this, one |
| 助動詞 | 動詞に**意味を付け加える** | 動詞の原形の直前に来る(can swim) | can, may, must, should, will |

## 各品詞のくわしい解説

### 1. 名詞(Noun)

- **役割**:主語(I like **dogs**)・目的語(**Dogs** are cute)/ 補語(This is **a pen**)として使う
- **種類**:普通名詞(book)、固有名詞(Japan)、物質名詞(water)、抽象名詞(love)、集合名詞(family)
- **見分け方**:a / an / the / my / this の直後に来る。複数形に -s / -es をつけられる

### 2. 動詞(Verb)

- **役割**:文の述語となり「いつ・誰が・何をしたか」の時制や主体を決める
- **種類**:be動詞(am/is/are/was/were)、一般動詞(play, go)、助動詞と組み合わさる本動詞
- **見分け方**:主語の次に来て、三人称単数なら -s、過去なら -ed など形が変わる

### 3. 形容詞(Adjective)

- **役割**:名詞の前から修飾(a **tall** boy)、または be動詞などの後ろで補語に(The boy is **tall**)
- **比較**:比較級 taller、最上級 the tallest(j12 比較)
- **見分け方**:名詞を説明しているか、「〜だ」という状態を be動詞の後ろで表しているか

### 4. 副詞(Adverb)

- **役割**:動詞(run **fast**)・形容詞(**very** tall)・他の副詞(so **quickly**)・文全体(**Luckily**, ...)を修飾
- **位置**:一般に文末が多いが、強調や頻度(always, usually など)では動詞の前・be動詞の後ろ
- **見分け方**:形容詞 + ly になっていることが多い(careful → carefully)。ただし fast, hard, late など変化しないものもある

### 5. 前置詞(Preposition)

- **役割**:前置詞 + 名詞で「場所・時・方向・手段」などを表す句を作る(**in** the park / **at** seven / **by** bus)
- **重要なもの**:in, on, at, to, for, from, of, by, with, about, near, between, during(j14 前置詞)
- **見分け方**:必ず名詞(または代名詞)を従える。「前置詞 + 名詞」でひとまとまり

### 6. 接続詞(Conjunction)

- **役割**:等位接続詞(and, or, but, so)は対等な語句・節をつなぐ。従位接続詞(when, if, because)は節を導く
- **見分け方**:2つの文・語句の間にあり、それ自体は文の要素にならない(j13 接続詞)

### 7. 代名詞(Pronoun)

- **役割**:すでに出た名詞を受けて繰り返しを避ける。主格(I, he)/所有格(my, his)/目的格(me, him)/所有代名詞(mine, his)
- **種類**:人称代名詞(I, you)、指示代名詞(this, that)、不定代名詞(one, some, all)、疑問代名詞(who, what)
- **見分け方**:名詞の代わりに主語・目的語の位置に置き換えられるか

### 8. 助動詞(Auxiliary Verb)

- **役割**:動詞の原形の前に置いて「できる・してもよい・しなければならない・だろう」などの意味を加える
- **ルール**:後ろは必ず動詞の原形。否定・疑問は助動詞自身で作る(can't swim / Can you swim?)
- **主要なもの**:can, may, must, have to, should, will(j10 助動詞、j11 未来表現)

## 文の中で品詞を見抜く例

> **My older brother can play the guitar very well.**

| 単語 | 品詞 | 働き |
|---|---|---|
| My | 所有格の代名詞 | brother を修飾 |
| older | 形容詞(比較級) | brother を修飾 |
| brother | 名詞 | 主語 |
| can | 助動詞 | play に「できる」の意味を追加 |
| play | 動詞(原形) | 述語 |
| the | 冠詞 | guitar を特定 |
| guitar | 名詞 | 目的語 |
| very | 副詞 | well を強調 |
| well | 副詞 | play を修飾 |

このように、**主語(名詞)+ 動詞**という骨格を見つけ、ほかの単語がどれを修飾・補足しているかを追えば、長い文も正確に読み解けます。
