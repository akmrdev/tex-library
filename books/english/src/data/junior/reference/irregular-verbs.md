# 不規則動詞変化表

英語の動詞のうち、過去形・過去分詞が規則的に変化しない**不規則動詞**の一覧です。中学3年で学ぶ現在完了・受動態・関係代名詞では過去分詞が頻出するため、この表を活用して確実に覚えましょう。

## 使い方

- **原形**:辞書に載っている基本の形(不定詞 to の後ろ・助動詞の後ろもこの形)
- **過去形**:過去進行形以外の過去の文(j08 過去形)で使用
- **過去分詞**:現在完了(j17)・受動態(j16)で使用
- 変化のパターン別にグループ分けしてあるので、まとめて覚えるのに役立ててください

## 覚え方のコツ

1. **まず be / have / go / do / come / see の6語**は最優先で暗記。現在完了・受動態の土台になります。
2. **A-A-A 型は数が少ない**ので一気に覚えてしまいましょう(cut, put, hit, let, cost, hurt, read)。
3. **A-B-B 型が一番多い**ので、「bought, thought, taught」など音でつながるグループごとに覚えるのが効率的です。
4. **A-B-C 型は歌のリズムに乗せて**(begin-began-begun、drink-drank-drunk…)口に出して覚えると定着します。
5. テスト前には「過去分詞だけ」を隠して自分で書き出す練習をするのがおすすめです。
