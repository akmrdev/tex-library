# 冠詞と数量表現(a/an/the/some/any)

> 対象: 中学2年 | 目安学習時間: 20分

## 📖 解説

英語では、名詞の前に **a / an / the** のような「冠詞」を置きます。日本語にはない考え方なので、まず基本ルールをしっかり押さえましょう。

### 不定冠詞 a / an(初めて出てくるもの・ひとつの)

| 使い方 | 例 |
|---|---|
| 子音の音で始まる名詞の前 | a dog, a book, a school |
| 母音の音で始まる名詞の前 | an apple, an egg, an old car |

- 「スペル」ではなく「音」で決まるのがポイント。
  - an hour(h は発音しないので母音扱い)
  - a university(u を「ユー」と読むので子音扱い)

### 定冠詞 the(話し手と聞き手がわかっているもの)

次のようなときに the を使います。

1. **すでに出てきたものをもう一度言うとき**
   - I have a dog. **The** dog is very cute.(犬を飼っています。その犬はとてもかわいい)
2. **文脈や状況から何を指すか明らかなとき**
   - Please close **the** door.(そのドア=この部屋のドア)
3. **世界にひとつしかないもの**
   - the sun, the moon, the earth

### some / any(数や量がはっきりしないとき)

| 単語 | 肯定文 | 疑問文・否定文 | 例 |
|---|---|---|---|
| some | ⭕ 使える | 基本使わない | I have **some** friends. |
| any | 基本使わない | ⭕ 使える | Do you have **any** brothers? / I don't have **any** money. |

- some は「いくつかの、多少の」、any は疑問文・否定文で「いくらかの」の意味になります。
- ※相手に物を勧めるときなどは疑問文でも some を使えます(Would you like some coffee?)。

### 数えられる名詞と数えられない名詞

- 数えられる名詞(countable):a book, two pens など。a/an や複数形と一緒に使える。
- 数えられない名詞(uncountable):water, money, bread, paper など。**a/an は付けず、複数形にもしない**。
  - ❌ a water → ⭕ water / a glass of water

### なぜそうなるのか?——理由で理解すれば忘れない

**Q. なぜ日本語にない冠詞が英語には必要なの?**

英語は「この名詞は、聞き手にとって新しい情報か、既知の情報か」を必ずしるしで示す言語だからです。a / an は「まだ話題に上っていない、どれでもいい1つ」、the は「もう特定済みの、あれだよねと共有できるもの」というタグ付け。日本語では文脈や「その・あの」で補う情報を、英語では名詞の直前に必ず刻み込む設計になっています。

**Q. なぜ疑問文では any、勧めるときは some?**

some の本質は「数量をぼかして軽く扱うニュアンス」だからです。Would you like some coffee? は「(ぜひ飲んでほしいので)コーヒーいかが?」という前向きな提案であり、“ぼかし”が丁寧さを生みます。一方 Do you have any brothers? は「いるかどうか自体が未知」なので、中立的に探す any が自然です。つまり any=疑問文というより、「確信ゼロで探すか(any)、ある前提で差し出すか(some)」の気持ちの問題です。

**Q. なぜ the sun に the が必要なの?**

世界にひとつしかないものは「どれのことか説明しなくても聞き手が特定できる」ため、the(=それ以外の候補を排除する印)が自動的につきます。逆に言えば the は“唯一性・特定性”の証明書なのです。

### よく出るセット表現

| 表現 | 意味 | 例文 |
| --- | --- | --- |
| play the + 楽器 | 楽器を演奏する | She plays the violin. |
| in the morning / afternoon | 朝に/午後に | I run in the morning. |
| go to bed / school | 寝る/登校する(the をつけない) | I go to school at eight. |
| at night | 夜に(the をつけない) | He reads at night. |
| How many + 複数形 | いくつの | How many books do you need? |
| How much + 不可算 | どのくらいの | How much money do you have? |

⚠️ school / bed / home など「本来の目的で利用する場所」には the をつけない(go to school = 登校する)のがポイント。the school(その学校[建物]へ)だと意味が変わります。

### 中学入試・実生活での使用例

- **入試頻出パターン**:a / an / the / ×(不要)の4択空所補充が王道。「I bought (　) camera yesterday. (　) camera was expensive.」のような2連続問題で「初出=a、再登場=the」を問うのが定番です。some / any の選択も毎年出ます。
- **実生活**:ホテルの案内(Don't leave any trash.)、レストランでの注文(Would you like some water?)、道案内(Go straight and turn left at the corner.)——the があるかないかで意味が変わる場面が日常にたくさんあります。
- **読解のコツ**:英文を読むとき、the を見つけたら「これ、前で出てきた?」と遡る習慣をつけると文章構造が掴めます。the は“戻る目印”として読解の最強の手がかりになります。

## ⚠️ よくある間違い

### ① 初めて出したのに the を使う

- ❌ I bought ~~the~~ **a** book yesterday. ~~The~~ **A** book was interesting.
- ⭕ I bought **a** book yesterday. **The** book was interesting.
- 解説:最初は a、2回目からは the。「聞き手がどれかわかっている」状態になってから the。

### ② 母音の音なのに a を使う

- ❌ I want to be ~~a~~ engineer.
- ⭕ I want to be **an** engineer.
- 解説:engineer はア行(母音)の音で始まるので an。

### ③ 数えられない名詞に a や複数形を使う

- ❌ Please give me ~~a breads~~.
- ⭕ Please give me **some bread**.
- 解説:bread は数えられない名詞。some + 名詞(単数形のまま)。

## 🔍 もっと深く知りたい人へ

### 発展的補足

- **the + 形容詞で「〜な人々」**:the rich(お金持ちの人々)/ the young(若者たち)。形容詞に the をつけると複数の人間の集まりを指せるのは高校受験レベルの発展形です。
- **固有名詞と the**:山(Mt. Fuji)や人名には通常 the をつけませんが、川(the Shinano River)、海(the Pacific Ocean)、楽器(play the piano)には the がつく、という傾向のまとめが入試で役立ちます。
- **any の肯定文用法**:「どれでもいいから」と強調するときは肯定文でも any を使えます(You can take any cookie you like.)。“選択肢を限定しない”という本質が見えれば理解が一段深まります。
- **no = not any**:I have no money. = I don't have any money.。no は「ゼロ」を直接宣言する語で、入試の書き換え問題(同じ意味に)でよく出ます。

### 類似文法との比較

| 項目 | a / an | the | some / any |
| --- | --- | --- | --- |
| イメージ | どれでもいい1つ | 特定済みのそれ | ぼかした量 |
| 使う場面 | 初登場・単数可算名詞 | 再登場・唯一のもの | 不特定の数・量 |
| 例 | I have a cat. | The cat is white. | some milk / any bread |

→ 「初めてか二度目か」「特定できるか」「量がぼやけているか」の3軸で判断します。j05 の可算/不可算の知識がそのまま土台になります。

### 覚え方のコツ(語呂合わせ)

- **「初対面はエー(an/a)、再会はザー(the)」**:人間関係にたとえます。初めて会った名詞とは a で握手、2度目からは the で「あいつね!」。この物語だけで大半の冠詞問題が解けます。
- **「サムは肯定、エニーは疑問・否定」**:Some=サンキュー(肯定)で覚え、Any=「あんた、ないんでしょ?」の疑いの口調で疑問・否定。ただし Would you like some ...?(勧め)だけは例外の“サムさんの特別サービス”と丸暗記。
- **「楽器には the、スポーツは裸」**:play the piano vs play soccer。音楽室のピアノには必ず“the のネームプレート”がついているイメージで対比暗記します。
- **「an は母音の音に寄り添う」**:an hour / an honest man の h は沈黙(honest の h も無音)。発音されない文字の前では a ではなく an が立つ、とセットで覚えましょう。

## ✏️ 練習問題

**A. 空所補充★基本**:空所に a / an / the を入れましょう(不要なら ×)。

1. There is (　　) old temple near my house.
2. I have two cats. (　　) cats are white.

**B. 空所補充★★標準**

3. Look at (　　) moon. It's so bright tonight!
4. Ken is (　　) student in my class.
5. Please open (　　) window.(この部屋の窓)

**C. some / any 選択★基本**

6. Are there (some / any) eggs in the refrigerator?
7. I want (some / any) milk for breakfast.
8. We don't have (some / any) homework today.
9. She gave me (some / any) flowers last week.

**D. 並び替え★★標準**

10. 私には何冊か英語の本があります。(have / books / English / some / I)

**E. 英作文★★標準**

11. 机の上に何かりんごがありますか?(any を使う)

**F. 応用問題★★★**

12. 日本語に合うように英文を作りましょう。
    「昨日、古いカメラを買いました。そのカメラはとても高かったです。」
13. 次の英文を、same の意味になるように書き換えましょう。
    I don't have any brothers or sisters. → I have (　)(　).

### 解答と解説

1. **an** … old はア行の音で始まるので an。❌ a がダメな理由:a / an は直後の語の最初の「音」で決まるため、母音で始まる old には a を置けません。
2. **The** … 前述の猫。❌ A cats のような形がダメなわけではなく、そもそも2回目の登場なので不定の a / an は使えず、特定の the が正解です。
3. **the** … 月は世界にひとつの存在。❌ a moon がダメな理由:唯一のものは「どれでもいい1つ」ではなく自動的に特定できるため、the が必須です。
4. **a** … student は子音の音で始まる可算名詞の単数形。❌ an がダメな理由:student は「ス」の子音から始まるため an の対象外です。
5. **the** … 状況からどの窓か明らか(この部屋の窓)。❌ a window がダメな理由:話し手と聞き手の双方が特定できるものに不定冠詞を使うと「どれでもいい窓」という別の意味になります。
6. **any** … 疑問文。❌ some がダメな理由:卵があるかどうかを確かめる中立の質問なので、基本的なルールどおり any を選びます(勧めの場面ではない点に注意)。
7. **some** … 肯定文。❌ any がダメな理由:「欲しい」という前向きな希望の文は肯定文なので、some が基本です。
8. **any** … 否定文。❌ some がダメな理由:don't のある否定文では some は原則使えません(no = not any の置換なら可能ですが、don't との併用は不可)。
9. **some** … 肯定文。❌ any がダメな理由:花をくれた事実をありありと述べる肯定文のため、「ぼかした量」を表す some が自然です。
10. **I have some English books.** … some + 複数形。❌ I have English some books. がダメな理由:some は名詞の直前に置く数量表現で、形容詞 English と名詞の間に入れられません(順序は some + 形容詞 + 名詞)。
11. **Are there any apples on the desk?** … There is / are の疑問文+ any。apples が複数なので are。❌ Is there any apple … がダメなわけではないものの、中学では「りんご(可算名詞)」は複数形+are の型で答えるのが標準です。
12. **I bought an old camera yesterday. The camera was very expensive.** … old camera は母音の音から始まるので an、再登場で the。❌ 二文目を The old camera にするのも可ですが、a camera → the camera の対応が問われている場合は the camera が無難です。❌ 一文目を a old camera にするのは音のルール違反で即アウトです。
13. **I have no brothers or sisters.** … no = not any の置換。❌ I have not brothers … がダメな理由:一般動詞 have の否定には do が必要で、not 単独では否定できません(j03 の復習)。
