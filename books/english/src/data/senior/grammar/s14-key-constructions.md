# 重要構文総まとめ(so that/not only A but also B/no sooner等)
> 対象: 高校3年 | 目安学習時間: 25分

## 📖 解説

高校英文法の仕上げとして、**入試で最頻出の重要構文**を一気に整理します。どれも整序問題・英作文・長文読解に直接結びつく「得点源」です。

### 主な構文一覧

| 構文 | 意味 |
|---|---|
| so that S can[may] V / so as to V | 〜するために(目的) |
| so ... that S cannot V | あまりにも〜なので…できない |
| not only A but also B | AだけでなくBも |
| no sooner had S p.p. than ... | 〜するや否や… |
| Hardly[Scarcely] had S p.p. when ... | 〜するや否や… |
| On -ing / On + 名詞 | 〜するとすぐに |
| It is worth -ing | 〜する価値がある |
| There is no -ing | 〜することは不可能だ |
| cannot help -ing / cannot but V | 〜せずにはいられない |
| as soon as / the moment | 〜するとすぐに |

### ポイント1:目的を表す構文の使い分け

| 構文 | 主語の制限 | 例 |
|---|---|---|
| so that S can V | なし(Sは主節と同じでも別でも可) | Speak clearly **so that everyone can hear** you. |
| so as to V | 主節と**同じ**主語 | He got up early **so as to catch** the first train. |
| in order to V | 主節と同じ主語(書き換えの基本形) | She left early **in order to avoid** the traffic. |

*so that* 節では can/may 以外に will も使え、過去文脈では could/might になります。

### ポイント2:not only A but also B のバリエーション

1. 基本形:He **not only** plays tennis **but also** enjoys golf.(動詞をまたぐ)
2. 主語:AだけでなくBも → **Not only he but also his parents are** coming.(動詞は近い方(B)に一致)
3. 文頭置き+倒置:**Not only did he apologize, but he also offered to pay.**(最頻出!)

### ポイント3:no sooner ... than / hardly ... when

どちらも「〜するや否や」。**過去完了+than/when** がセット。

> He had **no sooner arrived** at the office than the phone rang.
> = **No sooner had he** arrived at the office than the phone rang.(倒置版)
> = **On arriving** at the office, he found... / As soon as he arrived, ...

書き換え問題では *as soon as ↔ no sooner ... than ↔ on -ing* の相互変換が頻出です。

### ポイント4:「不可能・必然」の慣用表現

| 表現 | 意味 |
|---|---|
| There is no telling what will happen | 何が起こるか分からない(telling = 知ることはできない) |
| It is no use complaining | 不満を言っても無駄だ |
| I cannot help laughing | 笑わずにはいられない |
| You cannot be too careful | いくら注意してもしすぎることはない |

### 入試頻度メモ

- 整序問題の王道:*so that / not only ... but also / no sooner ... than*。
- 自由英作文では *so that*(目的)+*what*(名詞節)+*分詞構文*を使えると表現力が一段上がる。
- 「cannot too(いくら〜してもしすぎることはない)」「There is no -ing」は意味を取り違えると致命的なので確実に。

### 入試頻度評価(★3段階)

| 項目 | 頻度 | 出題のされ方 |
|---|---|---|
| no sooner ... than / hardly ... when | ★★★ | 書き換え・倒置・整序の三役をこなす万能素材。過去完了+接続詞のセット完答が得点条件 |
| so that S can V(so as to V) | ★★★ | 目的の英作文は国公立二次の定番中の定番。can の入れ忘れが典型ミス |
| Not only A but also B(文頭+倒置含む) | ★★★ | 相関接続詞の一致と倒置を同時に問える。s11 との連携問題も多い |
| There is no -ing / cannot help -ing | ★★☆ | 意味取り違え防止型の空所補充。中堅〜上位校で頻出 |
| cannot too / It is worth -ing | ★★☆ | 和訳で差がつく。*You cannot be too careful.* は有名フレーズ |

**なぜ頻出なのか**:この単元の構文は「同じ意味を複数の形で言い換える」相互変換ネットワークを作っています(as soon as ⇔ no sooner ... than ⇔ On -ing)。入試の書き換え問題はまさにこの変換能力を測るために設計されており、1構文ずつの丸暗記では対応できないよう作られています。

### セット表現表(重要構文の書き換えマップ)

| 意味 | 形A | 形B | 形C |
|---|---|---|---|
| 〜するとすぐに | As soon as S V, ... | No sooner had S p.p. than ... | On -ing, ... |
| 〜するために | so that S can[may] V | so as to[in order to] V | for the purpose of -ing |
| 〜せずにはいられない | cannot help -ing | cannot but V | cannot choose but V |
| 〜する価値がある | It is worth -ing | It is worth while to do | be worth -ing |

## 💡 例文

| # | 英文 | 日本語訳 |
|---|---|---|
| 1 | I spoke slowly so that the audience could follow me. | 聴衆がついてこられるように、ゆっくり話した。 |
| 2 | The problem was so difficult that nobody could solve it. | その問題は難しすぎて、誰も解けなかった。 |
| 3 | Not only does she sing well, but she also writes her own songs. | 彼女は歌がうまいだけでなく、自分の曲も作る。 |
| 4 | No sooner had we sat down than the movie began. | 私たちが座ったと思うとすぐに映画が始まった。 |
| 5 | On hearing the alarm, everyone rushed out of the building. | 非常ベルを聞くや否や、全員が建物から飛び出した。 |
| 6 | This guidebook is worth reading before your trip. | このガイドブックは旅行前に読む価値がある。 |
| 7 | You cannot be too careful when you cross the street. | 道路を渡るときは、いくら注意してもしすぎることはない。 |
| 8 | There is no denying that smartphones have changed our lives. | スマートフォンが私たちの生活を変えたことは否定できない。 |
| 9 | I cannot help feeling that he is hiding something. | 彼が何か隠している気がしてならない。 |
| 10 | Hardly had she entered the room when the phone rang. | 彼女が部屋に入ったと思うとすぐに電話が鳴った。 |
| 11 | It goes without saying that health is above wealth. | 健康は富に勝ることは言うまでもない。 |

## ⚠️ よくある間違い

1. ❌ No sooner had he entered the room **when** the lights went out.
   ⭕ No sooner had he entered the room **than** the lights went out.
   → no sooner の後ろは必ず than。when と組むのは hardly/scarcely。

2. ❌ Not only she sings beautifully, but she also dances well.
   ⭕ Not only **does she sing** beautifully, but she also dances well.
   → Not only を文頭に置いたら疑問文と同じ語順(助動詞を主語の前へ)。

3. ❌ He studied hard **for** pass the exam.
   ⭕ He studied hard **so that he could pass** the exam. / **to pass** the exam.
   → 目的の for の後ろに動詞の原形は来ない(to do / so that SV にする)。

## 🔍 もっと深く知りたい人へ

### なぜ「同じ意味」の形がこれほど多いのか

英語は文体(会話・文章・見出しなど)による言い換えの階層が細かい言語です。会話では *as soon as*、文章では *No sooner had ... than ...*、簡潔な叙述では *On -ing* と、場面に応じて register を使い分けます。入試が複数形を求めるのは、学習者が「意味ごとのネットワーク」を持っているかを確かめたいからです。「〜するとすぐに」という意味の棚に全部しまえるかが、この単元の勝負どころです。

### 類似文法との比較

| ひっかけペア | 違い |
|---|---|
| so that S can V(目的)/ so + 形容詞 + that SV(結果) | 目的は「〜するために」。結果は「あまりにも〜なので…」。can の有無が目印 |
| no sooner ... than / hardly[scarcely] ... when | 接続詞のペア違いだけ。混ぜて than+when にすると即誤答 |
| so as to / in order to | 意味は同じ。否定は so as not to / in order not to(so not to は不可) |
| cannot help -ing / cannot but V | help 版は動名詞、but 版は原形不定詞。cannot help but V も現代英語では可 |
| It is worth -ing / It is worth while to do | worth の直後は動名詞。worth while なら to do も可 |

### 覚え方のコツ

- **「や否や」は過去完了の独壇場**:had p.p. が見えたら接続詞は than か when の二択。no sooner→than、hardly/scarcely→when。
- **not only A but also B は「対等の品詞」を結ぶ**:動詞×動詞、名詞×名詞。文頭に置いたら倒置もセットで思い出す。
- **cannot too は肯定文なのに否定訳**:「いくら〜しても足りない=いくら〜してもしすぎることはない」。直訳の罠として最頻出。

### 上位向けの補足

- *so that* 節には目的以外に「その結果(so that = and so)」の用法もあるが、入試レベルでは can/may/could/might を伴っていれば目的と判断してよい。
- 書き換え候補には *On + 名詞*(*On his arrival*)もある。on の後ろが必ずしも動名詞ではない点に注意。

## ✏️ 練習問題

**1. 空所補充**:日本語に合うように( )に適切な語を入れなさい。

(1) Take your umbrella ( ) ( ) you won't get wet.(=濡れないように)

(2) ( ) ( ) had I left home than it started to rain.(=家を出たとたんに雨が降り出した)

(3) There is no ( ) how the story ends.(=物語がどう終わるかは分からない)

(4) We cannot ( ) admire her courage.(=彼女の勇気に感嘆せずにはいられない)

**2. 並び替え**:日本語に合うように並べ替えなさい。

(5) 彼は英語だけでなくフランス語も流暢に話す。
    only / speaks English fluently / French / not / but also.

(6) 彼女はとても親切なので、みんな彼女が大好きだ。
    is so / that everybody / kind / loves her.

**3. 英作文**:

(7) 「電車に間に合うように、私はタクシーで行った」を so that を使って書きなさい。

(8) 「彼が到着するや否や、会議が始まった」を as soon as と no sooner ... than の両方で書きなさい。

**4. 応用問題**(入試レベル):

(9)【★★☆】次の文を so ... that ... 構文を使って書き換えなさい。
    The box was too heavy for me to lift.

(10)【★★★】次の文の( )内の語を並べ替えなさい(1語余分にあります)。
    「雨が降り出したと思うとすぐに、私たちは雷の音を聞いた。」
    ( heard / it / no / rain / sooner / than / to / we / had / begun / when )

### 解答と解説

(1) **so that**(目的。「〜しないように」は so that + won't/can't)

(2) **No sooner**(文頭なので倒置+had。後ろは than)

(3) **telling**(There is no telling ...「〜かどうか分からない」)

(4) **help**(cannot help -ing。admire が -ing 形になるので help)

(5) **He not only speaks English fluently but also speaks French.**
    → not only A but also B は対等な要素をつなぐ。

(6) **She is so kind that everybody loves her.**
    → so + 形容詞 + that 節(結果)。

(7) **I went by taxi so that I could catch the train.**
    → so that + S + could(過去文脈)。might でも可。

(8) **As soon as he arrived, the meeting began.**
    **No sooner had he arrived than the meeting began.**
    → no sooner 版は過去完了+倒置+than の3点セット。

(9) **The box was so heavy that I couldn't lift it.**
    → too ... to は「〜すぎて…できない」と否定の含みを含むので、so ... that に書き換えるときは that 節の中を couldn't の否定にする。that I could lift にすると意味が正反対になる。

(10) **No sooner had it begun to rain than we heard thunder.**
    → when が余分な1語。no sooner の相手は必ず than。文頭に置いたので had が主語 it の前に出る倒置もセットで必要。
