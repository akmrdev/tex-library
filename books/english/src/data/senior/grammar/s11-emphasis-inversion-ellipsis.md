# 強調・倒置・省略(so neither倒置/Only then)
> 対象: 高校3年 | 目安学習時間: 25分

## 📖 解説

「**倒置**」は語順の変化で文を際立たせる技法です。国公立大の整序問題や長文中の難文に頻出するため、パターンごとに確実に覚えましょう。

### 倒置が起きる主なパターン

| パターン | 例 |
|---|---|
| 否定語句の文頭移動 | Never have I seen such a beautiful sunset. |
| so / neither[or] のみ | So do I. / Neither do I. |
| Only + 副詞(句・節) | Only then did I understand the problem. |
| 場所を表す副詞句 | Here comes the bus. / On the hill stands an old temple. |
| 譲歩の倒置 | Come what may, I will keep my promise. |
| so that 節内の倒置 | ..., so dense is it that light cannot escape. |

### ポイント1:否定語句の文頭で疑問文と同じ語順

never / seldom / little / not until A / no sooner had ... than ... / hardly ... when ... / by no means / in vain などが文頭に来ると、**助動詞(do/does/did/have/had/be)が主語の前に**出ます。

- **Never have I** seen the sea.(海など一度も見たことがない)
- **Not until yesterday did I** hear the news.(昨日になって初めてそのニュースを聞いた)
- **Little did they know** what would happen.(何が起ころうとは彼らはほとんど知らなかった)

### ポイント2:so / neither のみの倒置

前の文の内容を受けて「〜もまた」と言うときの短い返答。

| 返答 | 意味 | 条件 |
|---|---|---|
| **So do I.** | 私もそうだ | 前の文が肯定文 |
| **Neither do I.** / Nor do I. | 私もそうではない | 前の文が否定文 |
| So he does. | 彼は本当にそうだ | 主語が同一人物の確認(倒置なし) |

時制と助動詞を前の文に合わせるのがポイント。*I am happy.* → *So am I.*

### ポイント3:Only then / Only + 副詞(句)

only が then / later / recently / in this way などの副詞(句)とともに文頭に来ると倒置します。

> **Only then did I realize** how serious the situation was.
> そのときになって初めて、状況がどれほど深刻か気づいた。

*Only* + 主語の場合は倒置しない:**Only he knows the answer.**

### ポイント4:省略

| 種類 | 完全な形 → 省略形 |
|---|---|
| 関係代名詞の目的格 | a book (which) I bought |
| 不定詞のみ残す | Will you come? — I'd like to.(to 以降省略) |
| so/not の代用 | Do you think he'll win? — I think so. |
| 接続詞+分詞の省略 | (While) walking along the street, I met him. |
| 疑問詞以降の省略 | I'll help you (in) any way (that) I can. |

長文読解では、省略された語を補って意味を取る力が問われます。

### 入試頻度メモ

- *no sooner had p.p. than ...* と *Hardly[Scarcely] had p.p. when ...*(〜するや否や)は最頻出ペア。
- *So do I / Neither do I* は会話文問題の定番。
- 場所の副詞句の倒置(Here comes ~)では、**主語が代名詞だと倒置しない**(Here **it** comes.)点に注意。

### 入試頻度評価(★3段階)

| 項目 | 頻度 | 出題のされ方 |
|---|---|---|
| 否定語句文頭の倒置(no sooner / never / not until) | ★★★ | 整序・空所補充の王道。「助動詞を主語の前に出せるか」が得点条件 |
| so / neither のみの倒置 | ★★★ | 会話文問題の定番。前の文の時制・助動詞を複写できるかを試される |
| Only + 副詞(句)の倒置 | ★★★ | *Only then did I ...* は整序の常連。Only+主語では倒置しない、まで問われる |
| Not only 文頭+倒置 | ★★☆ | s14 とも連動する人気ネタ。but also 側との対応もセットで見られる |
| 省略(to の後の省略・so/not の代用) | ★★☆ | 会話文の空所補充で中堅頻出。I'd love to. 型 |

**なぜ頻出なのか**:倒置は「語順を変えても意味はほぼ同じ」という整序問題に最適な素材だからです。さらに否定語句の倒置は「疑問文と同じ語順にする」というルール理解をそのまま試せるため、出題者にとって採点しやすい、いわば“測りやすい単元”になっています。

### セット表現表(倒置を起こす語・句)

| 表現 | 意味 | 例 |
|---|---|---|
| No sooner had S p.p. than ... | 〜するや否や | No sooner had she sat down than the phone rang. |
| Hardly[Scarcely] had S p.p. when ... | 同上 | Hardly had I arrived when it began to rain. |
| Not until A did S V | Aして初めてVした | Not until midnight did he return home. |
| Little did S know that ... | 何が起ころうとはほとんど知らずにいた | Little did they know the danger ahead. |
| In vain did S try to do | 努力もむだに終わった | In vain did he attempt to open the door. |
| May S V!(願望) | 〜でありますように | May you succeed! |

## ⚠️ よくある間違い

1. ❌ Never **I have seen** such a mess.
   ⭕ Never **have I seen** such a mess.
   → 否定語句が文頭に来たら疑問文と同じ語順に。

2. ❌ "I don't like horror movies." "**So do I**."
   ⭕ "I don't like horror movies." "**Neither[Nor] do I**."
   → 否定文への同意は neither[nor] を使う。so は肯定への同意。

3. ❌ Only then **she realized** her mistake.
   ⭕ Only then **did she realize** her mistake.
   → Only + 副詞(then)が文頭なら助動詞 do/did が必要。

## 🔍 もっと深く知りたい人へ

### なぜ「疑問文と同じ語順」になるのか

*Never have I seen ...* の have I は、もともと疑問文の語順です。英語では、目立つ要素を文頭に出す代わりに「これは疑問文ではない」という合図として助動詞を主語の前に移動させます。つまり倒置とは**強調したい要素を前に出すために支払う“語順のコスト”**です。こう考えると、「なぜ助動詞が動くのか」への違和感が消えます。

### 類似文法との比較

| ひっかけペア | 違い |
|---|---|
| So do I. / So he does. | 「私もそうだ(倒置)」vs「本当にそうだ(同一人物への確認、倒置なし)」 |
| Neither do I. / Nor do I. | 全く同義。nor の方がやや文語的で硬い印象 |
| Only then did I ... / Only he knows ... | only+副詞(句)は倒置する / only+主語は倒置しない |
| Here comes the bus. / Here it comes. | 主語が名詞なら倒置 / 代名詞なら非倒置 |
| no sooner ... than / hardly ... when | ペアになる接続詞が違うだけ。than と when を混ぜると即誤答 |

### 覚え方のコツ

- **倒置トリガーは「否定・限定・場所」の3系統**:never 系(否定)/ only 系(限定)/ here・there 系(場所)。出てきた語がどの系統でも対応できる。
- **no sooner had p.p. than を音で丸暗記**:「ノースーナー・ハド・ザン」。when と混ぜない。
- **So do I の返答は「前の文の助動詞をコピー」**:be 動詞・助動詞があればそれを使い、一般動詞なら do/does/did。

### 上位向けの補足

- 譲歩の倒置(*Come what may*(何が起ころうとも)/ *Be that as it may*(それはさておき)/ *Say what you will*)は動詞が先頭に来る特殊型。難関校の長文中で確認程度に出る。
- *..., so strong is his will that ...* のような so that 節内の倒置は「so+形容詞」が文頭に来た結果生じるもの。s14 の so ... that と合わせて復習すると理解が早い。

### 解答と解説

(1) **does**(Seldom が文頭→倒置で does he arrive)

(2) **No sooner**(no sooner had p.p. than ...。「〜するや否や」)

(3) **Neither [Nor]**(否定文への同意。can't なので Neither can I も正しい表現になる)

(4) **Never did I agree to the proposal.**
    → never 文頭で did I agree の倒置。

(5) **Only then did I realize that she was lying.**
    → Only then + did + 主語 + 動詞の原形。

(6) **Never have I climbed Tokyo Tower.**
    → 現在完了の経験用法+倒置(have I climbed)。been to も可。

(7) **He didn't come, nor did his brother.**
    → nor の後ろは倒置(did his brother)。

(8) **Hardly had I left home when it started to rain.**
    → 過去完了の had が主語 I の前へ出る。hardly のペアは when。than に書き換えると no sooner 用の文になり、誤り。

(9) **Not only did he keep his promise, but he also apologized.**
    → was が余分な1語。Not only を文頭に置いたら疑問文と同じ語順(did he keep)。与えられた語が keep(原形)である点に注意——did があるので kept にはしない。

(10) **Neither [Nor] have I.**
    → 現在完了の助動詞 have をそのまま複写し、neither[nor]+倒置。So have I とすると「私も行ったことがある」になり、never との矛盾で会話が成立しない。
