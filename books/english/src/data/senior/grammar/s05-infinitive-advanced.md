# 不定詞の発展(重要構文: too~to/seem to等)
> 対象: 高校1年 | 目安学習時間: 25分

## 📖 解説

中学で学んだ不定詞の3用法(名詞的・形容詞的・副詞的)を土台に、高校では**頻出構文**をパターンで覚えることが重要です。入試では構文の識別+和訳が頻出です。

### 1. 不定詞の重要構文一覧

| 構文 | 意味 | 例 |
|---|---|---|
| too ... to ... | 「〜すぎて...できない」 | He is **too** young **to** drive. |
| ... enough to ... | 「〜するのに十分...だ」 | She is old **enough to** vote. |
| so ... as to ... | 「〜するほど...」 | He was **so** kind **as to** help me. |
| seem to / appear to | 「〜するようだ」 | He **seems to** be tired. |
| want to / would like to | 「〜したい」 | I **want to** travel abroad. |
| used to | 「以前はよく〜した」 | I **used to** play tennis. |
| be used to -ing | 「〜に慣れている」 | I am **used to** getting up early. |
| be about to | 「まさに〜しようとしている」 | The train is **about to** leave. |

### 2. too ... to ... の注意点

`too A to B` は**否定の意味**を含みます。「BするにはAすぎる → Bできない」という論理です。

- He is too young to drink. = He is **so** young that he **cannot** drink.

⭕ 書き換え対応(入試頻出):
```
too ... to ...    ⇔  so ... that ... cannot ...
enough to ...     ⇔  so ... that ... can ...
```

### 3. seem to の書き換え

| 不定詞レベル | It seems that ... への書き換え |
|---|---|
| He **seems to be** honest. | It seems that he **is** honest. |
| He **seems to have been** sick. | It seems that he **was** sick. |

不定詞が現在形ならthat節も現在形、不定詞が完了形(to have + p.p.)ならthat節は過去形になります。

### 4. 独立不定詞

文全体を修飾する慣用的表現です。

| 表現 | 意味 |
|---|---|
| To tell the truth | 正直に言うと |
| To begin with | まず第一に |
| To make matters worse | さらに悪いことに |
| To be frank | 率直に言えば |

### 5. 不定詞の意味上の主語

`for + 名詞` で「〜にとって」という主語を示せます。

- It is important **for you** to read books every day.
- 入試では `for` か `of` かの判別も頻出。kind, nice, wise, careless など人の性格を表す形容詞のときは `of` を使う(It was kind **of** you to help me.)。


### なぜ too ... to が否定になるのか(理由の説明)

`too A to B` の too は「必要な量を**超えている**」ことを示す副詞です。「Bするのに必要な度合いを超えてAだ → だからBできない」という論理が自動的に否定を生みます。だから very hot to drink ❌(very は単なる強調で超過の意味がない)となり、必ず too が必要です。

- 書き換え先の so ... that ... cannot ... の cannot は、この「超過 → 不可能」の論理を明示しているだけ。
- enough はその逆で「十分な量に達している → できる」。形容詞の後ろに置くのは、enough が程度を測る対象を前に置くイメージだから(old enough = old の程度が十分)。

### 入試頻度チャート

| 項目 | 頻度 | 出題形式 |
| --- | --- | --- |
| too ... to ⇔ so ... that cannot の書き換え | ★★★ | 書き換え・整序 |
| seem to(完了不定詞を含む) | ★★★ | 空所補充・書き換え |
| 意味上の主語 for / of の判別 | ★★☆ | 空所補充 |
| 独立不定詞 | ★★☆ | 整序・会話文 |
| be about to / be to | ★☆☆ | 空所補充 |

### セット表現表(追加の頻出構文)

| 構文 | 意味 | 例 |
| --- | --- | --- |
| too ... to ... | 〜すぎて…できない | too tired to walk |
| ... enough to ... | 〜するほど…だ | brave enough to say it |
| so ... as to ... | 〜するほど…だ(等価書き換え頻出) | so kind as to help |
| would rather A than B | BよりむしろAしたい | would rather stay than go out |
| cannot help -ing | 〜せずにはいられない | couldn't help laughing |
| be to ... | 予定・義務・運命など多義 | You are to be here by six. |
| not to mention | 〜は言うまでもなく | fast, not to mention cheap |

## ⚠️ よくある間違い

❌ This coffee is very hot to drink.
→ ⭕ This coffee is **too** hot to drink.
「too」がないと「飲むために熱い」という不自然な文になります。too ... to はセット構文。

❌ He is enough old to enter the school.
→ ⭕ He is old **enough** to enter the school.
enough は形容詞の**後ろ**に置きます(a enough big → a big enough ❌)。

❌ It seems that he is busy now. = He seems being busy now.
→ ⭕ He **seems to be** busy now.
seem の後ろは to不定詞。-ing形は来ません。



## 🔍 もっと深く知りたい人へ

### 発展①:完了不定詞(to have + p.p.)は「一段昔」を指す

- He seems **to be** honest.(今も正直そう)/ He seems **to have been** honest.(当時/昔から正直だったようだ)
- was supposed to have p.p.「〜したはずだった」や was to have p.p.「〜する予定だった(実現せず)」も上位校で頻出。

### 発展②:for か of かの判別の理屈

- `It is kind **of** you to help me.`:kind が「あなた」という人の性質を説明している(**It is kind of you. = You are kind.** の等式が成り立つ)。→ 人の性格を表す形容詞(kind, nice, wise, foolish, careless, polite)なら of。
- `It is difficult **for** me to read it.`:**It is difficult for me. ≠ I am difficult.**(私は難しい人ではない)。→ 性格形容詞以外は for。

### 発展③:覚え方(ゴロ)

- 独立不定詞は「文頭に来て文全体を修飾」。To tell the truth / To begin with / To make matters worse / To be honest / Needless to say の5つをセットで暗記。
- used to(以前はよく〜した)⇔ be used to -ing(〜に慣れている)⇔ be used to do(〜に使われる)の3兄弟は例文ごとセットで覚える。

### 発展④:be to の5つの意味

| 意味 | 例 |
| --- | --- |
| 予定 | The Queen is to visit Japan next month. |
| 義務 | You are to return it by Friday. |
| 可能 | Not a star was to be seen.(1つも見えなかった) |
| 運命 | He was never to see her again.(二度と会えなかった) |
| 意図(if we are to ...) | If we are to finish today, we must hurry. |

入試では特に「運命(never to see again)」と if we are to ... が狙われます。

### 発展⑤:so ... that と such ... that の使い分け

| 型 | 語順 | 例 |
| --- | --- | --- |
| so + 形容詞/副詞 + that | so **fast** that ... | He ran so fast that we couldn't catch him. |
| so + much/many/few/little + 名詞 | so **many books** that ... | She has so many books that she can't read them all. |
| such + 形容詞 + 名詞 | such **a good book** that ... | It was such a good book that I read it twice. |

- too/enough の書き換えは「形容詞」基準、この区別は「名詞があるか」基準。冠詞付きの名詞を含むなら such、形容詞・副詞だけなら so、と機械的に判定できます。

### 発展⑥:want / hope / wish の不定詞との相性

- want to do / want O to do(wish to do も可だがやや硬い)/ hope to do(hope O to do ❌)
- 「O に〜してほしい」を言えるのは want / expect / would like(expect him to come)。hope には O を取る用法がない点が試験ポイントです。

### 類似文法との比較

- **so ... as to と so ... that**:意味はほぼ同じ。簡潔に言いたいときは so ... as to、節で詳しく説明したいときは so ... that。試験の等価書き換えでは両方向が出ます。
- **want O to do と want O done**:I want you to check it.(あなたに確認してほしい)/ I want it checked by Friday.(金までにチェック済みである状態を望む)— C に入るのが原形不定詞か過去分詞かで「誰が動作するか」が変わります。

## ✏️ 練習問題

**問1** 次の英文の( )に適語を入れなさい。

1. The question was ( ) hard for me to answer.
2. He ran fast ( ) to catch the last train.
3. She seemed ( ) ( ) lost her way in the forest.(2語)

**問2** 次の英文を指定の通り書き換えなさい。

4. He is too young to solve this problem. (so ... that ... cannot ... を使って)
5. It seems that she was ill yesterday. (seem to を使って)

**問3** 次の日本語に合う英文になるように、( )内の語を並び替えなさい。

6. 彼はまさに出発しようとしていた。
( about / he / to / was / leave ).

7. 正直に言うと、私はそのニュースに驚いた。
( tell / to / truth / the ), I was surprised at the news.


**問4(応用)** 次の問題を解いて、レベルを確かめましょう。

8. (応用 ★☆☆)空所補充:She is so kind (　　　)(　　　) strangers the way.(as to を使う形にする)
9. (応用 ★★☆)書き換え:He seems to have been rich.(It seems that ... で始める)
10.(応用 ★★★)英作文:「私にとってその規則を守るのは難しい。」(意味上の主語 for を使う)

### 解答と解説

1. **too** — too ... to 構文。「難しすぎて答えられない」
2. **enough** — 動詞fastの後ろなので fast enough to。「間に合うほど速く走った」
3. **to / have** — seem to have + p.p.(完了不定詞)=「〜したようだ」。過去のこと。
4. He is **so** young that he **cannot** solve this problem. — too ... to の等価書き換え。young の位置に注意。
5. She **seemed to have been** ill yesterday. — that節が過去形(was)なので完了不定詞 to have been。
6. **He was about to leave.** — be about to =「まさに〜しようとしている」
7. **To tell the truth**, — 独立不定詞。「正直に言うと」


8. **She is so kind as to show** strangers the way.(= She is kind enough to show ...)。very ❌ — very kind as to という形は存在しない。too ❌ — 否定の意味になり「親切すぎて道を教えられない」と不自然になる。
9. **It seems that he was rich.** — 完了不定詞 to have been は that 節では過去形 was に戻る。is ❌ — 今も金持ちという意味になり、to have been の持つ「過去」の情報が消えてしまう。
10. **It is difficult for me to follow (obey) the rule(s).** — difficult は人の性質を表さないので for。of ❌ — It is difficult of me は I am difficult(私は厄介な人だ)という誤った等式を作ってしまう。
