# 仮定法(過去・過去完了・were to)

> 対象: 高校2年 | 目安学習時間: 25分

## 📖 解説

仮定法は「**現実とは違うこと**を想像して言う」ための表現です。時制をひとつ前にずらすことで、実現の可能性が低いことや、実際には起きなかったことを表します。入試では空所補充・整序・自由英作文のすべてで頻出の最重要単元です。

### 基本の3形

| 種類 | if節の中身 | 主節 | 意味 |
| --- | --- | --- | --- |
| 仮定法過去 | 過去形(be は were) | would / could / might + 動詞の原形 | 今の事実に反する仮定「もし〜なら、…のに」 |
| 仮定法過去完了 | had + 過去分詞 | would / could / might have + 過去分詞 | 過去の事実に反する仮定「もし〜だったなら、…しただろうに」 |
| 仮定法未来(were to) | were to + 動詞の原形 | would / could / might + 動詞の原形 | 実現可能性が極めて低い将来の仮定 |

- **事実との対応**:仮定法過去 →「今は〜でない」/ 仮定法過去完了 →「実際には〜しなかった」
- **were の特別感**：仮定法では主語が I / he / she でも **were** を使うのが正式。If I **were** you, ... 「もし私があなたなら」は会話の定番表現。

### その他の重要ポイント

- **if の省略と倒置**:If I were you → **Were I you** / If he had known → **Had he known** / should を使った If it should rain → **Should it rain**(助動詞 should とは別物)。
- **If it were not for ... / If it had not been for ...**「もし〜がなければ」:Without / But for でも置き換え可能。
- **wish + 仮定法**:I wish I **had** more money.(今の願望)/ I wish I **had studied** harder.(過去への後悔)。as if も同じ発想(as if he **were** / as if she **had seen**)。
- **混合仮定法**：if節と主節の時点がずれる場合。If I **had taken** the medicine yesterday, I **would be** better now.(yesterday=過去完了側 / now=仮定法過去側)
- **should + 原形(万一〜なら)**：仮定法未来の1つ。should が付くと「起こる可能性は低いが万一起きたら」のニュアンス。

### 入試での頻度

- 共通テスト・国公立2次・私立ともに、**仮定法過去完了の空所補充**(would have + 過去分詞)が最頻出。
- 整序問題では「If it were not for / Without」+ 名詞 の形が定番。
- 自由英作文・面接では「If I were you, I would ...」「I wish I had ...」のような実用的フレーズがそのまま使えます。


### なぜ時制をずらすのか(理由の説明)

仮定法の核心は「**現実からの距離**」を文法的に示すことです。英語では「ありえない話ほど、時制を前にずらす」ルールで距離感を表現します。

- 仮定法過去(If I were rich)→ 今の現実から1ステップ離れる →「今は金持ちではない」という事実が自動的に伝わる。
- 仮定法過去完了(If I had studied)→ 2ステップ離れる →「過去に起きなかったこと」への後悔・反実仮想になる。
- つまり「時制をずらす = 現実ではないサイン」。この原理は wish や as if でもまったく同じです。

### 入試頻度チャート

| 項目 | 頻度 | 出題形式 |
| --- | --- | --- |
| 仮定法過去完了(would have + p.p.) | ★★★ | 空所補充・整序 |
| If it were not for / Without / But for | ★★★ | 整序・書き換え |
| wish + 仮定法 | ★★★ | 空所補充・英作文 |
| if の省略と倒置(Were / Had / Should) | ★★☆ | 整序・長文 |
| 混合仮定法 | ★★☆ | 長文・正誤(上位校) |
| were to / should + 原形 | ★☆☆ | 空所補充 |

### セット表現表(仮定法の慣用フレーズ)

| 表現 | 意味 | 例 |
| --- | --- | --- |
| If I were you, I would ... | 私があなたなら〜するのに | 定番アドバイス表現 |
| If it were not for O / Were it not for O | もしOがなければ(今) | 後ろは仮定法過去 |
| If it had not been for O / Had it not been for O | もしOがなければ(過去) | 後ろは仮定法過去完了 |
| I wish + 過去形 / 過去完了 | 今の願望 / 過去への後悔 | I wish I knew the answer. |
| as if + 過去形 / 過去完了 | まるで〜であるかのように | She talks as if she knew everything. |
| would rather + 原形 than ... | BよりむしろAしたい | I would rather stay home. |
| It is time + 過去形 | もう〜する時間だ | It is time you went to bed. |

## 💡 例文

| # | 英文 | 日本語訳 |
| --- | --- | --- |
| 1 | If I were rich, I would travel around the world. | もし私が金持ちなら、世界一周旅行をするのに。(今、金持ちではない) |
| 2 | If I had studied harder, I could have passed the exam. | もっと勉強していたら、試験に合格できただろうに。(実際は不合格) |
| 3 | Were I in your position, I would accept the offer. | もし私があなたの立場なら、その申し出を受け入れるでしょう。(if省略の倒置) |
| 4 | If the sun were to disappear, all living things would die. | 万一太陽が消えたら、すべての生物は死ぬでしょう。(まず起きない未来) |
| 5 | If it had not been for your help, we would have failed. | あなたの助けがなければ、私たちは失敗していただろう。 |
| 6 | I wish I could speak French as fluently as you. | あなたのようにペラペラフランス語を話せたらいいのに。 |
| 7 | She looked as if she had seen a ghost. | 彼女は幽霊を見たかのような顔をしていた。 |
| 8 | If I had taken the earlier train, I would be in Tokyo now. | もっと早い電車に乗っていたら、今頃東京にいるだろうに。(混合仮定) |

## ⚠️ よくある間違い

1. 仮定法過去完了のはずが単純な過去形に
   - ❌ If I **had** time yesterday, I would help you.
   - ⭕ If I **had had** time yesterday, I **would have helped** you.

2. If I were you での was 使用(正式には不可)
   - ❌ If I **was** you, I would apologize first.
   - ⭕ If I **were** you, I would apologize first.(口語では was も聞かれるが、試験では were)

3. wish 文での時制のずらし忘れ
   - ❌ I wish I **can** fly.
   - ⭕ I wish I **could** fly.(現在の願望は can→could と一段階ずらす)

4. without / but for なのに仮定法の形にしない
   - ❌ Without water, no living things can survive. (文脈によっては可だが仮定の意図なら)
   - ⭕ Without water, no living things **could** survive.(仮定を含意するなら could/would を使う)


## 🔍 もっと深く知りたい人へ

### 発展①:仮定法過去が「丁寧表現」になる理由

Could you ...? / Would you ...? / I would like ... は実は仮定法過去の形です。

- Can you help me?(直接的)→ Could you help me?(控えめで丁寧)
- 理由:「実現できるかどうかを少しぼかす」= 現実から1ステップ離す仮定法の発想そのもの。押しつけを避ける心理が時制をずらすので、依頼ほど丁寧になります。

### 発展②:if 省略の倒置を一覧化

| 通常 | 倒置 | 条件 |
| --- | --- | --- |
| If I were you | Were I you | were のみ |
| If he had known | Had he known | had + p.p. |
| If it should rain | Should it rain | should + 原形 |

⚠️ 倒置できるのは were / had / should の3つだけ。If he was rich → Was he rich ❌、If I knew → Knew I ❌(一般動詞・were以外のbe動詞は倒置不可)。

### 発展③:覚え方(ゴロ)

- 主節の助動詞は「would / could / might」の3兄弟。can→could、may→might と過去形にするだけ。
- 「had + p.p. を見たら反実仮想」— had + p.p. は「実際には〜しなかった」のフラグ。
- wish のずらし段数:「今の願いは1段、過去の後悔は2段」。as if も同じ段数。

### 発展④:should + 原形(that節の中の should)との区別

- It is important **that he (should) be** honest.(提案・重要などで that 節内が should + 原形/原形になる仮定法現在の名残)
- この should は「万一〜なら」の should とは別物。アメリカ英語では should を省き原形にします。
- 入試では It is natural / necessary / important that ... の空所補充で頻出。

### 類似文法との比較

- **普通の条件文(直説法)との違い**:If it rains tomorrow, ...(明日降るかも=普通の可能性)/ If it **should** rain tomorrow, ...(万一起きたら=低い可能性)。形の違いが確率の違いを運んでいます。
- **hope と wish**:I hope it clears up.(実現可能な期待=直説法)/ I wish it would clear up.(実現が怪しい願望=仮定法)。wish の後に can は来ません(I wish I can ❌)。

## ✏️ 練習問題

**問1** 空所に適切な語を入れなさい。

1. If I (　　　) a bird, I would fly to you.
2. If he had left home earlier, he (　　　)(　　　) missed the train.
3. I wish I (　　　)(　　　) to her party last night. 行けたなら(go)
4. (　　　) it not been for music, my life would be boring.

**問2** 次の英文を仮定法を使って書き換えなさい。

1. As I don't know her address, I can't write to her.(If で始める)
2. He didn't study hard, so he failed the exam.(With... ではなく With 以外で。Had he studied... の倒置を使う)

**問3** 並び替えなさい。

1. 私があなたなら、その提案を断りますよ。
   ( I / would turn down / you / were / if / the offer / I ) .
2. もっと早く出発していれば、渋滞に巻き込まれなかったのに。
   ( if / we / had left / earlier / we / wouldn't have been / caught in ) .

**問4** 英作文しなさい。

1. もし私に十分なお金があったら、世界中を旅するでしょう。
2. 君の手伝いがなければ、私はその仕事を終わらせられなかっただろう。


**問5(応用 ★☆☆)** 空所に適切な語を入れなさい。

1. If it (　　　) not for air, nothing could live on the earth.(現在の仮定)
2. I wish I (　　　) taller.(残念ながら背が低い)

**問6(応用 ★★☆)** 次の英文を、指定された形で書き始めて書き換えなさい。

1. As she didn't take a map, she got lost.(Had で始める)
2. It is raining now, so we can't play tennis.(If で始める)

**問7(応用 ★★★)** 混合仮定法を使って英作文しなさい。

「もっと早く出ていれば、今頃駅に着いていただろうに。」

### 解答と解説

**問1**
1. were(仮定法過去では be動詞は were)
2. would not have(would not have missed「遅刻しなかっただろう」)
3. could have gone(wish + 過去完了で過去の不可能な願望)
4. Had(= If it had not been for ... の if省略倒置)

**問2**
1. If I knew her address, I could write to her.(現在の事実に反するので仮定法過去)
2. Had he studied hard, he wouldn't have failed the exam.(If を省略して had を倒置)

**問3**
1. If I were you, I would turn down the offer.
2. If we had left earlier, we wouldn't have been caught in (the traffic jam).

**問4**
1. If I had enough money, I would travel around the world.
2. If it hadn't been for your help, I couldn't have finished the work.(= But for / Without your help, ... も可)


**問5(応用解答)**
1. **were** — If it **were** not for ... が正式(it でも were を使う)= Were it not for air = Without air。was ❌ — 試験では were 一択。
2. **were** — wish + 仮定法過去。am ❌ — 現実の陳述になり「かなわぬ願い」が出ない。

**問6(応用解答)**
1. **Had she taken** a map, she wouldn't have got(gotten) lost. — if を省略して had を主語の前に倒置。She didn't take ❌ — 倒置形では過去形ではなく had + p.p. が必要。
2. **If** it weren't raining now, we could play tennis. — 現在進行中の事実に反するので、if 節は仮定法過去の進行形(weren't raining)。so we can't の部分は主節に移り can't → could に変えるのがポイント。

**問7(応用解答)**
If I had left earlier, I would have arrived at the station by now.
- left earlier(過去の反実仮想)= had left / by now(現在までの結果)= would have arrived。
- 「過去の原因 → 現在の結果」のズレが混合仮定の核心。両方を過去完了にすると「過去の時点での結果」の意味になり、now と噛み合わなくなります。
