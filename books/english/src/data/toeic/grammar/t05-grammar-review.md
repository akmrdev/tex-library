# Part5で出る文法ポイント総復習

> 対象: TOEIC L&R 全スコア帯 | 目安学習時間: 30分

## 📖 解説

TOEIC Part5(短文穴埋め)は全40問・1問あたり平均20秒で解くセクションです。実は出題ジャンルはほぼ固定で、**10の文法ジャンル**を押さえるだけで8割以上を安定して処理できます。まずは全体マップを見てください。

### 頻出10ジャンル一覧(出題頻度順)

| # | ジャンル | 出題頻度 | 見分け方のサイン |
| --- | --- | --- | --- |
| 1 | 品詞問題(語形選択) | 約30% | 空所の直前直後が名詞/動詞/形容詞 |
| 2 | 動詞の時制・相 | 約12% | 文中に by next month / yesterday など |
| 3 | 前置詞・接続詞 | 約10% | 空所が in / on / because / although の選択肢 |
| 4 | 関係詞 | 約8% | 名詞の後に空所が来る |
| 5 | 代名詞・指示語 | 約7% | it / its / they / their の選択肢 |
| 6 | 比較 | 約6% | than / as / most を含む文 |
| 7 | 受動態 | 約5% | by 句や be + 過去分詞の形 |
| 8 | 仮定法 | 約4% | if + 過去形/過去完了, would/could |
| 9 | 不定詞・動名詞 | 約4% | to V か V-ing かの選択肢 |
| 10 | 分詞(前置修飾) | 約3% | 名詞の前に V-ing / V-en が置かれる |

### 各ジャンの解き方の要点

| ジャンル | 一発で正解するための要点 |
| --- | --- |
| 品詞 | 「空所に入る品詞」を先に決めてから選択肢を見る。冠詞+空所→名詞、be動詞+空所→形容詞/受動態 |
| 時制 | 時を表す副詞句(by Friday, since 2020)が最大の手がかり。完了形と現在形の使い分けはこの1点 |
| 前置詞 | 自動詞/他動詞の区別+頻出イディオム(arrive at, consist of)をセットで暗記 |
| 関係詞 | 先行詞が人か物か、空所の後に主語+動詞が完全か不完全かだけ見る |
| 代名詞 | 入る場所に「名詞が必要」なら所有格、「名詞不要」なら代名詞/所有代名詞 |
| 比較 | 比較級には than、最上級には the、原級比較には as...as というセットで判断 |
| 受動態 | 主語が動作を受ける側か確認。by 以外にも in/on/at が使われる受動態もある |
| 仮定法 | if節の時制が1つ未来→過去形、2つ前→過去完了。would/could/might が答えの目印 |
| 不定詞/動名詞 | stop/remember/forget は両方取るが意味が変わる。目的語の後は不定詞になりがち |
| 分詞 | 名詞が「している」なら V-ing、「されている」なら V-ed(V-en)。能動/受動の見極め |

### 品詞問題の3パターン(最重要)

| パターン | 例 | 正解の条件 |
| --- | --- | --- |
| 冠詞/a/an/the の後 | the ___ report | 名詞 |
| be動詞の後 | The plan is ___ | 形容詞または過去分詞 |
| 動詞を修飾する位置 | ___ completed the task | 副詞 |

### 時制問題を解くための時制キーワード一覧

| キーワード | 導かれる時制 |
| --- | --- |
| yesterday / last week / ago | 過去形 |
| since / for / already / yet | 現在完了 |
| by + 未来時点 | 未来完了 |
| now / currently / at the moment | 現在進行形 |
| tomorrow / next month / soon | 未来形 |
| when / as soon as + 現在形 | 主節は未来形(if/when 節内は現在形) |

### Part5とPart6の関係

Part5で問われる文法は、そのままPart6(長文穴埋め)にも出ます。違いは「文脈を読む量」だけなので、Part5で固めた知識はそのまま転用できます。逆に言えば、**Part6が苦手な人はPart5の基礎に穴がある**ことが多いのです。

### 解く順番(20秒ルーティン)

| 手順 | 行うこと | 所要時間 |
| --- | --- | --- |
| 1 | 空所の前後2〜3語だけを見る | 3秒 |
| 2 | 入る品詞 or 文法形式を仮決定 | 5秒 |
| 3 | 選択肢から仮決定と合うものを選ぶ | 7秒 |
| 4 | 迷ったらマークして先へ進む | 5秒 |

## 🎯 実践ステップ

1. **ジャンル別ドリルで弱点診断**: 本アプリの Part5 ドリル(part5-drill-40)を1周し、間違えた問題を10ジャンル別に集計する。
2. **頻度上位3ジャンル(品詞・時制・前置詞)から潰す**: この3つだけで約5割。ここを正答率90%にすれば600点ラインは突破できる。
3. **1問20秒のタイムトライアル**: レベル別ドリル(range400 → range600 → range730)で制限時間を守る練習をする。
4. **間違えた問題は「なぜ」まで言語化**: 「知らなかった」のか「読み飛ばした」のかを記録する。
5. **週1回、総復習クイズで再テスト**: 忘却曲線に沿って同じジャンルを再出題する。

## 💡 具体例

**例1: 品詞問題**

> All employees are required to submit the form ___.
> (A) prompt (B) promptly (C) prompts (D) promptness

submit は他動詞なので「動詞を修飾する副詞」が必要 → **(B)**。

**例2: 時制**

> By the end of this quarter, the company ___ three new offices.
> (A) opens (B) opened (C) will have opened (D) has opening

by + 未来時点 → 未来完了 → **(C)**。

**例3: 仮定法**

> If we ___ more time, we could revise the proposal.
> (A) had (B) have had (C) will have (D) would have

could がある=仮定法過去。if節は過去形 → **(A)**。

## ⚠️ よくある失敗

| 失敗 | 原因 | 対策 |
| --- | --- | --- |
| 全文を精読して時間切れ | Part5を長文のように読む | 空所の前後だけ読む訓練をする |
| 品詞問題で意味から選ぶ | 単語の意味に引きずられる | 「入る品詞」を先に確定する癖をつける |
| 時制問題で現在形を選ぶ | by/since の意味理解が曖昧 | 時制キーワード一覧を暗記する |
| 仮定法を見逃す | if に注意が向きすぎる | would/could/might を見たら if を探す逆算も使う |
| 同じジャンルで繰り返しミス | 弱点の集計をしていない | アプリの解答履歴を週次で分析する |

## ✏️ 確認クイズ

**Q1.** 次の空所に入るのはどの品詞? 「The manager gave a ___ explanation of the new policy.」

**Q2.** 「She ___ in Singapore since 2019.(lived / has lived)」正しい方を選べ。

**Q3.** 「If the shipment ___ delayed, please contact us immediately.(were / is)」仮定法ではなく普通の条件文として正しい方を選べ。

<details>
<summary>解答</summary>

1. **形容詞**(冠詞 a の後、名詞 explanation を修飾する位置)
2. **has lived**(since 2019 = 過去からの継続 → 現在完了)
3. **is**(immediately で現実の指示を表す=直接法の現在形。if があれば必ず仮定法ではない点に注意)
</details>
