# Part5短文空所補充・Part6長文空所補充の攻略

> 対象: TOEIC学習者 | 目安学習時間: 30分

## 📖 パート概要(問題数・時間・点数配分の表)

| パート | 形式 | 問題数 | 時間 | 特徴 |
|---|---|---|---|---|
| Part5 | 1文の空所に最も適する語句を選ぶ | 30問 | 75分(全リーディング共通) | 1問1文。速解きが命 |
| Part6 | 3つの長文(手紙・E-mail等)の空所を選ぶ | 16問 | 〃 | 文章全体の流れを読む必要がある |

- リーディング75分のうち、Part5+6は合計18〜25分で終わらせるのが理想です。
- 残りの50〜57分を配点最大のPart7に回します。

## 🎯 攻略ポイント(解法フローチャート)

### 品詞問題の見分け方(3秒判断)

空所の**直前直後**を見て、入れるべき品詞を判断します。

| 空所の形 | 入る品詞 | 例 |
|---|---|---|
| 冠詞/形容詞 + ( ) + 名詞 | 形容詞 | a very ___ report → **useful**(形容詞) |
| ( ) + 動詞/形容詞/副詞 | 副詞 | The team worked ___ → **efficiently**(副詞) |
| the + ( ) + of | 名詞 | the ___ of the project → **completion**(名詞) |
| 主語 + 助動詞 + ( ) | 動詞の原形 | She will ___ the data → **analyze**(動詞) |
| be動詞 + ( ) + by 〜 | 過去分詞(受動態) | The plan was ___ by the board → **approved** |

選択肢が「develop / development / developing / developed」のように同じ語の変化形なら、ほぼ確実に品詞問題です。

### 解法フローチャート

1. **選択肢を見る** — 同じ語の変化形なら「品詞問題」、前置詞4つなら「前置詞問題」、接続詞4つなら「接続詞問題」と判断。
2. **空所の前後だけ読む** — 品詞問題は全文不要。前後3〜5語で判断できます。
3. **文構造を確認する** — 接続詞問題なら「前節と後節の関係は理由か? 対比か? 時制か?」を判断。
4. **残った2択で意味から決める**

### 時制・相の頻出ルール

| キーワード | 正しい時制・形 |
|---|---|
| since / for / so far / recently | 現在完了(have + 過去分詞) |
| yesterday / last year / in 2019 | 過去形 |
| tomorrow / next week / by Friday | 未来形(will / is going to) |
| every day / usually / often | 現在形(習慣) |

### 紛らわしい語の使い分け早見表

| 語 | 使い方の目安 |
|---|---|
| since / because / due to | since・because + 主語述語 / due to + 名詞 |
| affect / effect | affect=動詞 / effect=名詞 |
| between / among | between=2者の間 / among=3者以上の中で |
| although / despite | although + 主語述語 / despite + 名詞 |
| if / unless | unless = if not の意味 |

## ⏱ 時間配分

| パート | 1問あたりの目安 | 合計 |
|---|---|---|
| Part5 | 20〜30秒 | 10〜15分 |
| Part6 | 30〜40秒(空所以外も軽く読む) | 8〜10分 |

- 迷ったら即マークして先へ進み、Part7が終わってから戻ります。
- 「1問30秒ルール」を守れないと、配点の大きいPart7で時間切れになります。
- 模試のときからストップウォッチでPart5の所要時間を計り、自分のペースを数値化しておきましょう。

## 💡 例題パターン(出題例と解き方)

| 出題例 | 正解 | 解き方 |
|---|---|---|
| All employees are required to ___ the training session. (attend / attendance / attentive / attentively) | attend | to + 動詞の原形(to不定詞) |
| The manager spoke ___ about the new policy. (confident / confidently / confidence / confide) | confidently | 動詞を修飾するのは副詞 |
| We will ship the order ___ Monday. (in / on / at / for) | on | 曜日・日付には on |
| ___ the price is high, the product sells well. (Despite / Although / Because / Unless) | Although | 「高い」のに「売れる」=逆接。後ろに主語述語があるのでAlthough |
| Please find attached the report ___ you requested. (what / which / who / whose) | which | 物を修飾する関係代名詞 |

### Part6特有の出題パターン

| パターン | ポイント |
|---|---|
| 文法・品詞の空所(Part5と同じ) | 前後だけでOK |
| 語彙の空所 | 文脈全体の意味が必要 |
| 文挿入問題(文中どこに入れるか) | 代名詞・接続詞の指す内容で位置を特定 |
| 文末の一文選択 | 手紙の結びの定型文を覚えておく |

## ⚠️ よくある落とし穴

1. **全文を丁寧に読んで時間を使いすぎる** — Part5は前後数語で解けます。全文精読は配点最大のPart7での時間不足を招き、総得点が下がります。
2. **Part6で文章を無視して空所だけ解く** — Part6は文脈問題(特に文挿入問題)が含まれるため、「文章全体を見る」ことが前提です。Part5と同じ感覚で解くと落とします。
3. **紛らわしい語の区別をあいまいにしたまま放置する** — affect/effect、between/among などの頻出ペアは、間違えたときに必ずノートにまとめて定着させましょう。
4. **前置詞問題を文法書で完璧にしようとしすぎる** — 前置詞は「曜日・日付には on」のような頻出ルールだけで大部分が解けます。出る順に優先度をつけて覚えましょう。

## ✏️ 確認クイズ

**問1** 選択肢が「succeed / success / successful / successfully」のような同じ語の変化形の場合、まず何を判断すればよい?(選択肢: ① 全文の和訳 ② 空所に入るべき品詞 ③ 単語の暗記度)

**問2** "The meeting was ___ due to heavy snow." の空所にはどれが入る?(選択肢: ① cancel ② canceled ③ cancellation ④ canceling)

**問3** Part6では、空所の前後だけでなく文章全体を読む必要がある。(○ or ×)

### 解答と解説

**問1: ② 空所に入るべき品詞**
同じ語の変化形なら品詞問題です。空所の直前直後を見て3秒で品詞を判断しましょう。

**問2: ② canceled**
was + 過去分詞の受動態です。「会議は中止された」という受け身の形が必要ですね。

**問3: ○**
Part6には文脈から解く問題(語彙問題・文挿入問題)が含まれます。Part5とは違い、文章全体の流れを掴んでから解きます。
