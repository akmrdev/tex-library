# 目標スコア別 学習プランテンプレート

> 対象: TOEIC L&R 全スコア帯 | 目安学習時間: 25分

## 📖 解説

戦略(unit:t07)が決まったら、それを**週次スケジュール**に落とし込みます。この単元では3ヶ月プランと6ヶ月プランの2つのテンプレートを提示します。基本方針は「平日15分 × 週末1時間」でも十分に結果を出せる設計です。

### 3ヶ月プラン(目標: +100〜150点)

| 週 | フェーズ | 平日15分 | 週末1時間 |
| --- | --- | --- | --- |
| 1〜2 | 現在地測定 | コア単語デッキ(新規10語/日) | フル模試①+徹底分析 |
| 3〜4 | 弱点集中① | Part5ドリル(range400/500)×5問 | 最弱ジャンルの文法復習50問 |
| 5〜6 | 弱点集中② | ビジネス語彙デッキ開始 | リスニング Part2 特訓 |
| 7〜8 | 形式慣れ | Part3/4 のシャドーイング音声 | Part3 先読み練習 |
| 9〜10 | 実戦演習 | レベル別ドリル(range600)タイムトライアル | フル模試②+分析 |
| 11〜12 | 調整 | 間違えた問題の総復習 | フル模試③(本番同日同時刻) |

### 6ヶ月プラン(目標: +200点以上)

| 月 | フェーズ | 主な内容 |
| --- | --- | ---|
| 1 | 基礎固め | コア語彙デッキ完走、5文型・時制の再構築 |
| 2 | 文法完成 | Part5頻出10ジャンル(unit:t05)を全部クリア |
| 3 | 中盤戦 | リスニング150デッキ、Part2/5 の安定化 → 中間模試 |
| 4 | 応用語彙 | ビジネス発展デッキ、Part3/4 先読み技術 |
| 5 | 実戦 | 句動詞デッキ、Part7 時間短縮、月次模試 |
| 6 | 仕上げ | 全範囲シャッフル復習、模試2回で仕上げ |

### 平日15分の使い方テンプレート

| 分 | 行うこと |
| --- | ---|
| 0〜5 | 単語デッキ(SRS復習優先) |
| 5〜12 | ドリル5問(タイマー必須) |
| 12〜15 | 間違えた問題の解説を読む |

### 週末1時間の使い方テンプレート

| 分 | 行うこと |
| --- | ---|
| 0〜20 | その週の弱点ジャンル集中ドリル |
| 20〜40 | リスニング特訓(シャドーイング含む) |
| 40〜55 | Reading の時間計測パート演習 |
| 55〜60 | 来週の焦点を決めてメモ |

### プラン選択の目安

| 条件 | 推奨プラン |
| --- | --- |
| 目標まで+100点以内、平日15分確保できる | 3ヶ月プラン |
| 目標まで+150点以上、または1日10分しか取れない | 6ヶ月プラン |
| 本番まで2ヶ月を切っている | 3ヶ月プランの第7週以降から開始 |

### 模試モードの活用タイミング

| タイミング | 目的 |
| --- | ---|
| プラン開始直前 | ベースライン測定(ここがないと効果検証できない) |
| 中間時点(3ヶ月プランなら第6週) | 方向修正。弱点の入れ替え判断 |
| 本番2〜3週前 | 実戦形式での時間配分の最終調整 |
| 本番直前(1週間前) | 本番と同じ曜日・同じ時間帯に受験して体内時計を合わせる |

模試は「受けっぱなし」が最大の無駄です。**受験後48時間以内にパート別・ジャンル別の分析を終える**のが鉄則です。

### 継続のコツ(習慣化の設計)

- 平日15分は「必ず同じ時間・同じ場所」に紐づける(行動のトリガーを作る)。
- 週次レビューで小さな達成(正答率+5pt など)を可視化して自分に還元する。
- 3日サボったら責めず、翌日から「復習のみの10分」で再開する。ゼロの日を作らないより、短い再開の方が復帰は速い。

## 🎯 実践ステップ

1. **今日ベースライン模試を受ける**: プランは模試の結果から始まる。
2. **カレンダーに平日15分を固定登録**: 「通勤中」「昼休み」など具体的な枠を決める。
3. **第1〜2週はコアデッキ+初回ドリル**: unit:t06 の SRS 設定を済ませる。
4. **毎週日曜に週次レビュー10分**: 今週の正答率と来週の焦点を1行メモする。
5. **模試後は必ず48時間以内に分析**: アプリの解答履歴エクスポートを使う。

## 💡 具体例

**例1: 平日15分の実際**

朝の電車でコアデッキ30語を復習(5分)→ 昼休みに range500 ドリル5問(7分)→ 夕方に朝の間違い3問だけ再テスト(3分)。合計15分で「暗記+演習+再テスト」の1サイクル。

**例2: 週末1時間の実践(第5週)**

弱点分析で「前置詞52%」「関係詞58%」が判明 → 週末は前置詞・関係詞のみのドリル40問を20分、残りをリスニングに充てる。

**例3: 模試タイミングの設計**

3ヶ月後に本番がある場合: 第0週に模試①、第6週に模試②、本番1週前に模試③。各模試間に弱点集中サイクルを2回ずつ挟む。

## ⚠️ よくある失敗

| 失敗 | 原因 | 対策 |
| --- | ---| --- |
| 平日に2時間やろうとして挫折 | ハードル設定ミス | 平日は15分で固定、伸びたければ+α |
| 模試を受けっぱなし | 分析が面倒 | 受験直後にアプリで集計する習慣化 |
| 計画変更を恐れて続行 | サンクコストへの執着 | 中間模試で悪ければフェーズを飛ばしてよい |
| 週末の1時間が溶ける | 内容を決めていない | 上記テンプレートを印刷/メモして貼る |
| 本番直前に新しい教材を始める | 焦りから手広くやりすぎる | 直前2週間は既習範囲の復習のみ |
| 記録をつけない | 効果が見えずモチベーションが切れる | 週次レビューの1行メモを必ず残す |

## ✏️ 確認クイズ

**Q1.** 3ヶ月プランでフル模試を受験すべき回数とタイミングを挙げよ。

**Q2.** 模試を受けてから分析を完了すべき期限は?

**Q3.** 平日15分テンプレートにおける最初の5分で行うことは?

<details>
<summary>解答</summary>

1. **3回**(開始直前=ベースライン / 第9〜10週=中間効果測定 / 本番直前=最終調整)
2. **48時間以内**
3. **単語デッキのSRS復習**(新規より復習優先)
</details>
