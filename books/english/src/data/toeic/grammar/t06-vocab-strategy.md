# 単語暗記の最適解—忘却曲線に挑む

> 対象: TOEIC L&R 全スコア帯 | 目安学習時間: 25分

## 📖 解説

TOEICで必要な語彙は約5,000語と言われます。しかし「1回覚えて終わり」の暗記では、1ヶ月後に残っているのは2〜3割だけです。この単元では、科学的根拠のある**間隔反復(SRS)**と**コロケーション暗記**という2つの武器を紹介します。

### 忘却曲線の現実

エビングハウスの忘却曲線によれば、記憶は時間経過とともに急激に失われます。

| 学習後の経過時間 | 記憶の残存率(復習なし) |
| --- | --- |
| 20分後 | 約58% |
| 1時間後 | 約44% |
| 1日後 | 約33% |
| 6日後 | 約25% |
| 31日後 | 約21% |

つまり、**忘れる直前に復習する**ことで記憶の減衰曲線は緩やかになり、最終的には長期記憶として定着します。

### 間隔反復(SRS)の原理

SRS(Spaced Repetition System)は「思い出すのにちょうど苦労するタイミング」で復習を配置します。

| 復習回数 | 推奨タイミング | 目的 |
| --- | --- | --- |
| 1回目 | 学習直後(当日) | 忘却カーブの最初の急落を防ぐ |
| 2回目 | 翌日 | 中期記憶への引き上げ |
| 3回目 | 3日後〜1週間後 | 苦労して思い出させる |
| 4回目 | 2週間後 | 定着確認 |
| 5回目以降 | 1ヶ月後、3ヶ月後… | 長期記憶へ移行 |

ポイントは **「正解できた項目の間隔を伸ばし、間違えた項目は間隔をリセット」** すること。これがアプリ型フラッシュカードが自動でやってくれることです。

### コロケーションで覚える利点

単語1つではなく**よく一緒に使われる語のペア(コロケーション)**で覚えると、次の4つの利点があります。

| 利点 | 内容 |
| --- | --- |
| 文脈で出る | TOEIC本番は単語ではなく文・フレーズで出題される |
| 思い出しやすい | 「meet + a deadline」のようにセットなら想起の手がかりが増える |
| 品詞問題に強くなる | 前置詞や副詞の形まで含めて覚えるので Part5 の品詞問題に直結 |
| スピーキングにも転用可能 | チャンク(意味のかたまり)として出力に使える |

例: submit a report(報告書を提出する)/ attend a meeting(会議に出席する)/ comply with regulations(規制を遵守する)

### 音とセットで覚える(リスニングデッキとの連動)

単語は「目」だけでなく「耳」でも覚えると定着率が大きく上がります。視覚だけの学習では、リスニング中にその語を音として認識できません。

| 学習モード | 定着への効果 |
| --- | --- |
| 目で見て意味を確認 | 認識語彙の獲得 |
| 声に出して音読 | 発音と綴りの接続 |
| 音声を聞いて意味が出る | 使用語彙(リスニング)への昇格 |

アプリのデッキ学習時に音声再生をONにし、「聞いて→意味を出す」方向でも1回タップすることをおすすめします。

### 本アプリのデッキ活用法

アプリには4つの単語デッキがあります。**推奨学習順序は次の通りです。**

| 順序 | デッキ | 対象レベル | 到達目安 |
| --- | --- | --- | ---|
| ① | tw-core-100(頻出コア) | 全スコア帯 | まず600点ラインの土台 |
| ② | tw-business-100(ビジネス発展) | 600点以上 | 730点突破の中核語彙 |
| ③ | tw-part1-4-listening-150(リスニング150) | 全スコア帯 | Part1〜4の音声語彙 |
| ④ | tw-idioms-phrasal-100(熱語句動詞) | 730点以上 | 860点帯の差がつく句動詞 |

コア→発展の順で固めると、難しい語も既知の語との関連で覚えやすくなります。リスニングデッキは並行でも構いませんが、句動詞デッキは最後に回すのが効率的です。

## 🎯 実践ステップ

1. **デイリー15分を固定**: 毎日同じ時間にデッキ学習をする(習慣のハードルを下げる)。
2. **新規20語+復習50語の配分**: 新規より復習を多くして SRS の効果を最大化。
3. **答え合わせは「音読」で**: 正解した語も1回声に出す。視覚+聴覚の二重符号化。
4. **週末に苦手リストだけ再テスト**: アプリの不正解履歴を週1でまとめて回す。
5. **月1回、前月の全範囲シャッフル**: ジャンル順の記憶(位置記憶)を崩して本当の定着を確認。

## 💡 具体例

**例1: コロケーション暗記の実践**

× implement(実施する)だけ覚える
○ implement **a policy / a plan / measures**(政策/計画/対策を実施する)
→ 本番で「The company will ___ the new policy.」が出たら即答できる。

**例2: SRSの間隔設計**

月曜に100語学習 → 当日夜10分で全語再確認 → 火曜に翌日分+昨日の100語 → 土曜に1週間分を一括復習。アプリのスケジュール機能がこれを自動化します。

**例3: 句動詞の差がつく場面**

call off(中止する)= cancel と知っていれば、「The meeting was called ___.(off/up/out)」のような問題は瞬殺できます。

## ⚠️ よくある失敗

| 失敗 | 原因 | 対策 |
| --- | --- | ---|
| 帳面に単語帳を書き写すだけ | 手を動かしている感覚に安心する | 書くより「見て即答→音読」を繰り返す |
| 新規単語ばかり進める | 復習は退屈に感じるため | 復習:新規 = 2:1 以上を守る |
| 日本語訳だけ覚える | 英和対応だけで満足する | 例文・コロケーションごと覚える |
| 一度覚えた語を放置 | 「もう大丈夫」という過信 | SRSの間隔スケジュールに従い続ける |
| 難デッキから始める | 句動詞など応用から入る | コア→発展の順序を守る |

## ✏️ 確認クイズ

**Q1.** SRSで「思い出すのにちょうど苦労するタイミング」で復習する理由は何か?

**Q2.** 本アプリ推奨のデッキ学習順序を、最初と最後のものを挙げよ。

**Q3.** attend と set のコロケーションとして自然な組み合わせを選べ。(a meeting / a deadline)(up a meeting / up a rule)

<details>
<summary>解答</summary>

1. **思い出す努力を伴う復習ほど長期記憶への定着効果が高いため**(検索練習効果)。楽すぎても苦しすぎても効率が落ちる。
2. 最初は **tw-core-100(頻出コア)**、最後は **tw-idioms-phrasal-100(熱語句動詞)**。
3. attend **a meeting**(会議に出席する)/ set **up** a rule(ルールを設立する)。「set up a meeting」も可だが「set up a deadline」は不自然。
</details>
