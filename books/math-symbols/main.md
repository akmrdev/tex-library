# この辞典のために

この辞典は、図書館の教科書に出てくる**数学記号**を引くための本です。Markdown + KaTeX で書かれているため、記号はそのまま美しく表示されます。「あの記号なんて読むんだっけ?」という瞬間に開いてください。

カテゴリ別に並べています。数式の詳しい使い方は、各項目末尾の「→」で元の教科書に飛べます。

# 記号: 集合と論理

| 記号 | 読み方 | 意味 | 例 |
| --- | --- | --- | --- |
| $\in$ | 属する(いん) | $x$ が集合 $A$ の元 | $3 \in \mathbb{N}$ |
| $\notin$ | 属さない | 元でない | $-1 \notin \mathbb{N}$ |
| $\subset$ | 部分集合 | 全部の元が相手にも属する | $\mathbb{N} \subset \mathbb{R}$ |
| $\emptyset$ | 空集合(くうしゅうごう) | 元を 1 つも持たない集合 | $\{x \mid x^2 < 0\} = \emptyset$ |
| $\cap$ | 共通部分(インターセクション) | 両方に属する元の集合 | $A \cap B$ |
| $\cup$ | 和集合(ユニオン) | どちらかに属する元の集合 | $A \cup B$ |
| $\forall$ | すべての(フォーオール) | 全称命題 | $\forall x,\ P(x)$ |
| $\exists$ | 存在する(イグジステンス) | 存在命題 | $\exists x,\ P(x)$ |
| $\lnot$ | 否定(ノット) | ではない | $\lnot P$ |
| $\Rightarrow$ | ならば | 論理的な含意 | $P \Rightarrow Q$ |

→ 詳しくは『大学数学入門』第 1 節

# 記号: 数と式

| 記号 | 読み方 | 意味 | 例 |
| --- | --- | --- | --- |
| $\pm$ | プラスマイナス | 両方の符号を表す | $\pm\sqrt{2}$ |
| $\times, \div$ | かける、わる | 乗法・除法 | $2 \times 3 = 6$ |
| $\le, \ge$ | 以下、以上 | 等号を含む不等号 | $x \le 5$ |
| $\ne$ | 等しくない | 否定の等号 | $x \ne 0$ |
| $\approx$ | 近似的に等しい | ほぼ等しい | $\pi \approx 3.14$ |
| $\sqrt{x}$ | ルート(平方根) | 2 乗して $x$ になる数 | $\sqrt{9} = 3$ |
| $|x|$ | 絶対値 | 0 からの距離 | $|-3| = 3$ |
| $a^x$ | a の x 乗 | 冪(べき) | $2^3 = 8$ |
| $\log_a x$ | 対数(たいすう) | $a$ を何乗すると $x$ か | $\log_2 8 = 3$ |
| $\mathbb{N}, \mathbb{Z}, \mathbb{R}$ | 自然数・整数・実数の集合 | 太字は集合を表す慣習 | $x \in \mathbb{R}$ |

# 記号: 統計と確率

| 記号 | 読み方 | 意味 | 例 |
| --- | --- | --- | --- |
| $P(A)$ | P エー | 事象 A の確率 | $P(A) = 0.5$ |
| $P(A \mid B)$ | 条件付き確率 | B のもとでの A の確率 | $P(A \mid B) \ne P(A)$ |
| $E[X]$ | 期待値(エックス) | 確率で重みづけた平均 | $E[X] = 3.5$ |
| $V[X], \sigma^2$ | 分散(ぶんさん) | ばらつきの指標 | $V[X] = 2.92$ |
| $\sigma$ | シグマ | 標準偏差(分散の平方根) | $\sigma = 10$ |
| $\bar{x}$ | x バー | 標本平均 | $\bar{x} = 50$ |
| $\mu$ | ミュー | 母平均 | $N(\mu, \sigma^2)$ |
| $\binom{n}{k}$ | 二項係数 | 組合せの数 | $\binom{4}{2} = 6$ |
| $\sim$ | に従う | 分布の指定 | $X \sim N(0, 1)$ |
| $N(\mu, \sigma^2)$ | 正規分布 | 釣り鐘型の連続分布 | $X \sim N(50, 10^2)$ |

→ 詳しくは『統計学入門』第 4〜6 節

# 記号: 線形代数

| 記号 | 読み方 | 意味 | 例 |
| --- | --- | --- | --- |
| $\boldsymbol{a}$ | ベクトル(太字) | 成分の組 | $\boldsymbol{a} = (1, 2)$ |
| $A^{\top}$ | 転置(てんち) | 行と列を入れ替え | $(AB)^\top = B^\top A^\top$ |
| $A^{-1}$ | 逆行列 | $AA^{-1} = I$ となる行列 | 正則のときのみ存在 |
| $I$ | 単位行列 | 掛けても変わらない行列 | $AI = A$ |
| $\det A$ | 行列式(ディターミナント) | 拡大率・正則性の指標 | $\det A \ne 0$ |
| $\mathrm{tr}(A)$ | トレース | 対角成分の和 = 固有値の和 | $\mathrm{tr}(A) = 6$ |
| $\|\boldsymbol{a}\|$ | ノルム | ベクトルの長さ | $\|(3,4)\| = 5$ |
| $\boldsymbol{a} \cdot \boldsymbol{b}$ | 内積 | 同じ向きの度合い | 直交なら 0 |
| $\lambda$ | ラムダ | 固有値 | $A\boldsymbol{v} = \lambda \boldsymbol{v}$ |
| $\mathrm{rank}(A)$ | ランク | 張る空間の次元 | $\mathrm{rank}(I) = n$ |

→ 詳しくは『大学数学入門』第 2〜5 節 / 『線形代数 応用編』

# 記号: 解析(微積分・級数)

| 記号 | 読み方 | 意味 | 例 |
| --- | --- | --- | --- |
| $f'(x)$ | f ダッシュ(ダイ) | 導関数 | $f'(x) = 2x$ |
| $\frac{df}{dx}$ | df dx いち(微分) | 導関数の別表記 | $\frac{d}{dx}x^2 = 2x$ |
| $\frac{\partial f}{\partial x}$ | 偏微分(ヘンダイビブン) | 他の変数を固定して微分 | $\partial f/\partial x$ |
| $\nabla f$ | ナブラ | 勾配ベクトル | 最急上昇方向 |
| $\int_a^b f\,dx$ | インテグラル | 定積分(面積) | $\int_0^1 x\,dx = 1/2$ |
| $\lim_{x \to a}$ | 極限(リミット) | 限りなく近づけた行き先 | $\lim_{x\to0}\frac{\sin x}{x} = 1$ |
| $\sum_{k=1}^{n}$ | シグマ(総和) | k=1 から n まで足す | $\sum k = n(n+1)/2$ |
| $\prod$ | パイ(総乗) | 全部掛ける | $\prod k$ |
| $\infty$ | 無限大 | 極限の行き先 | $\int_1^\infty$ |
| $\to$ | 矢印(近づく) | 収束・写像 | $n \to \infty$ |

→ 詳しくは『大学数学入門』第 6〜9 節

# 記号: 確率過程・投資の数学

| 記号 | 読み方 | 意味 | 例 |
| --- | --- | --- | --- |
| $X_n$ | ランダムウォークの位置 | 時刻 n の状態 | $X_{n+1} = X_n + \varepsilon_n$ |
| $P$ | 遷移行列 | 状態遷移の確率表 | $\pi P = \pi$ |
| $\pi$ | 定常分布 | 遷移しても変わらない分布 | マルコフ連鎖 |
| $E$ | 期待値係数 | 賭け 1 回あたりの期待損益 | $E = p(b+1) - 1$ |
| $f^*$ | ケリー比 | 最適賭け割合 | $f^* = (bp - q)/b$ |
| $u, d$ | 上昇・下落倍率 | 二項モデルの価格変化 | $S_0 u, S_0 d$ |
| $\Theta$ | セータ | 時間経過の感度 | オプションのグリーク |
| $\Delta$ | デルタ | 価格変動の感度 | 同上 |

→ 詳しくは『確率過程入門』/『投資の数学』/『オプションの数学入門』

# おわりに — 記号は約束事

数学記号は「世界共通の約束事」ですが、実は分野や本によって多少の方言があります(分散を $\sigma^2$ と書くか $V[X]$ と書くか等)。この辞典は**図書館の教科書での使われ方**に統一してあります。記号を見て引く習慣がつくと、数式の読解速度が一段速くなります。新しい教科書が増えたら、この辞典も更新していきます。
